# Hotel Room Reservation Management System

## Project Overview
This project is a desktop application developed to manage hotel room reservations.

It was developed using Java Swing for the graphical user interface and PostgreSQL for database management.

## Technologies Used
- Java
- Java Swing
- PostgreSQL
- NetBeans IDE
- Object-Oriented Programming (OOP)

## Main Features
- Graphical user interface developed with Java Swing
- Database connectivity using PostgreSQL
- Hotel room and reservation data management

## Development Environment
Developed using NetBeans IDE.
